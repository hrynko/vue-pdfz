# Internationalization

Nine locales ship built in – `ar`, `de`, `en`, `es`, `fr`, `he`, `ja`, `ko`, and `zh` – with interpolation, RTL, and `Intl` number formatting. Every user-facing string is a typed key on `LocaleMessages`.

Resolution order for any string: [adapter](#add-an-optional-vue-i18n-adapter) (if installed) → per-component `messages` → plugin `messages` → built-in bundle for the locale → `en`. So missing keys always fall back to English.

## Override individual strings

```vue
<PdfViewer
  :messages="{
    download: 'Export',
    thumbnailLabel: 'Sheet {page}',
  }"
/>
```

## Add a locale

```ts
import { en, type LocaleMessages } from 'vue-pdfz'

const it: LocaleMessages = { ...en, nextPage: 'Pagina successiva' /* ... */ }

// Per instance:
// <PdfViewer locale="it" :messages="it" />

// Or app-wide via the plugin:
// app.use(VuePdfz, { locale: 'it', messages: { it } })
```

## Add an optional `vue-i18n` adapter

With an adapter to a host [`vue-i18n`](https://github.com/intlify/vue-i18n) instance, keys resolve as `${prefix}${key}` (the default prefix is `vuePdfz.`), with unresolved keys falling back to the built-in bundle.

```ts
import { createI18n } from 'vue-i18n'
import VuePdfz, { createVueI18nAdapter } from 'vue-pdfz'

const i18n = createI18n({
  locale: 'en',
  messages: {
    en: {
      vuePdfz: {
        download: 'Export',
      },
    },
  },
})

app.use(i18n).use(VuePdfz, {
  i18nAdapter: createVueI18nAdapter(i18n.global),
})
```

The viewer follows the `vue-i18n` locale as it changes. Pass `{ prefix: 'pdf.' }` as the second argument to use a different key namespace.

## RTL

The text direction is derived from the locale and applied via `dir`; the layout uses CSS logical properties so the toolbar and sidebar flip automatically. The CJK locales (`ja` / `ko` / `zh`) are left-to-right and need no special configuration.

## CJK documents (character maps)

The `ja` / `ko` / `zh` bundles localize the **viewer UI**. Rendering CJK text that is **embedded in a PDF** sometimes needs PDF.js character maps. If glyphs are missing, point the source at the maps shipped with [`pdfjs-dist`](https://npmjs.com/package/pdfjs-dist):

```vue
<PdfViewer
  :source="{
    cMapPacked: true,
    cMapUrl: '/cmaps/', // copy from node_modules/pdfjs-dist/cmaps
    url: '/document.pdf',
  }"
  locale="zh"
/>
```
